Agent Onboarding Guide

Configure your AI agent to connect to the Task Manager MCP server in a few minutes.

🔑 Step 0 — Get Your API Key

Every agent needs an API key to authenticate with the MCP server. You can get one in three ways:

  • Via MCP (programmatic): Call the user_signup tool at https://task-man.co.in/mcp. It auto-creates your first agent and returns an api_key — save it immediately, it's shown only once.
  • Via Dashboard: Log in, then go to Agents → create or view an existing agent to copy its key.
  • Via CLI: python3 cli.py user signup --email you@example.com --password yourpass

The MCP endpoint is https://task-man.co.in/mcp. Authenticate with the header Authorization: Bearer YOUR_API_KEY.

Configuration by Platform

🤖 Claude Code (CLI)

One command. Replace YOUR_API_KEY with your actual key. 

claude mcp add task-manager \
  --transport http \
  --header "Authorization: Bearer YOUR_API_KEY" \
  https://task-man.co.in/mcp

Verify: claude mcp list should show task-manager.

🖥️ Claude Desktop

Edit your Claude Desktop config file, then restart the app.

Config file: ~/Library/Application Support/Claude/claude_desktop_config.json (macOS) or ~/.config/Claude/claude_desktop_config.json (Linux). Use Settings → Developer → Edit Config to open it. 

{
  "mcpServers": {
    "task-manager": {
      "type": "http",
      "url": "https://task-man.co.in/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}

If your Claude Desktop version doesn't support type: http directly, use the mcp-remote bridge: npx mcp-remote https://task-man.co.in/mcp --header "Authorization: Bearer YOUR_API_KEY".

⚙️ Cursor

Create or edit .cursor/mcp.json in your project root (or ~/.cursor/mcp.json for global). 

{
  "mcpServers": {
    "task-manager": {
      "url": "https://task-man.co.in/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}

Tip: Use "Bearer ${env:TM_API_KEY}" instead of a hard-coded key to keep secrets out of your repo.

☁️ Kiro (AWS)

Edit .kiro/settings/mcp.json (workspace) or ~/.kiro/settings/mcp.json (global). Open the command palette and search for Kiro: Open MCP Config. 

{
  "mcpServers": {
    "task-manager": {
      "url": "https://task-man.co.in/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}

Kiro supports streamable-http and sse transports. The headers object accepts any custom HTTP headers your server needs.

🌐 Any MCP-Compatible Client

The server speaks streamable HTTP (MCP 2025 spec). Any client that supports remote MCP with custom headers will work.

Setting Value
Transport streamable-http
Endpoint URL https://task-man.co.in/mcp
Auth Header Authorization: Bearer <your-api-key>
